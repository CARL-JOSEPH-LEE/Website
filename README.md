<h1 align="center">DJCARL · 小宇宙</h1>

<p align="center">好玩 · 好看 · 好听 · 会一点浪漫</p>

<p align="center">原生前端 / 三套心情主题 / 实时音乐可视化 / 轻互动个人主页</p>

<p>把自我介绍做成一次有配色、有节拍、有一点心动的见面。这里有我的兴趣、常驻平台、私藏歌单，也有可以随手开启的约会灵感和聊天小游戏。你点一下，我们就多认识一点。</p>

<h2>把播放器做成一个小型现场</h2>

<p>按下播放，底部的悬浮播放器就亮起一座霓虹舞台。中央低音冲高，两侧高频展开，粉紫与冰蓝交织，分段光柱、峰值拖影、底部倒影和鼓点粒子一起响应音乐。</p>

<p>画面由 Web Audio API 实时分析音频，再交给 Canvas 绘制。28 个对数频段配合快速起跳、自然回落和节拍检测，让鼓点有冲击、细节有层次。暂停时，整幅音浪连同拖影与粒子定格在最后一帧；继续播放，画面重新跟上音乐。</p>

<p>内置 11 首音乐，支持切歌、自动播放下一首和记住上次曲目。音乐按下播放才加载，普通模式频谱目标约每秒 60 次更新；针对内置浏览器限制动画帧的情况，也准备了播放期间的备用刷新。</p>

<h2>三种心情，都有自己的光</h2>

<p>Pink 是粉色的甜，Purple 是紫夜的酷，Cyan 是蓝绿的柔。渐变背景、玻璃质感卡片、柔和光晕和飘落爱心一起组成页面的氛围，主题一键切换，并记住你的选择。</p>

<p>电脑上舒展呈现，手机上自然排布。兴趣标签、社交链接、互动卡片和音乐控制保持清晰，让这个小宇宙在不同屏幕上都能好好展开。</p>

<h2>认识一个人，也可以很好玩</h2>

<p>抽一个约会灵感，复制一句开场白，回答一个暧昧问题，或者接下一个心动挑战。连续抽取会避开上一次结果，聊得来的话题可以直接复制带走。</p>

<p>从街健、钢琴、哲学到算法、围棋、日麻和音游，兴趣标签与八个平台入口把我的不同侧面放在一起。随便逛逛，也许就能找到共同话题。</p>

<h2>视觉有存在感，加载有分寸</h2>

<p>页面使用原生 HTML、CSS 和 JavaScript，零第三方运行时依赖，也不需要后端服务。当前发布图片连同 favicon 合计约 24 KB，HTML、CSS、JavaScript 经 Brotli 压缩后合计约 16 KB；音乐独立按需加载。</p>

<p>头像优先加载，链接图标延迟加载，图片预留尺寸。音频分析器和 Canvas 等到首次播放才初始化，暂停或进入后台就停止音浪刷新，爱心数量也会随屏幕和设备情况调整。</p>

<p>构建自带资源内容哈希以及 Brotli、gzip 副本；预览服务支持缓存验证和音频分段请求。项目包含自动化检查，覆盖真实频谱、暂停定格、快速切歌、异常恢复、主题记忆和手机横竖屏。好看的部分认真做，日常使用的细节也认真打磨。</p>

<h2>在本地打开这个小宇宙</h2>

<p>安装 Node.js 20.19 或更新版本，在项目目录运行：</p>

<pre><code>npm run dev</code></pre>

<p>浏览器访问 <a href="http://127.0.0.1:4173/">http://127.0.0.1:4173/</a>，点击播放即可体验实时音浪。启动页面无需先安装依赖；依赖仅用于浏览器自动化测试。直接双击 index.html 也能打开页面，但完整音频可视化需要通过 HTTP 或 HTTPS 访问。</p>

<h2>换成你的故事</h2>

<p>在 index.html 修改名字、兴趣和社交链接，在 app.js 调整灵感、问题、挑战与歌单逻辑，在 styles.css 调整三套主题和视觉细节。assets 存放页面使用的轻量图片，根目录的 1.mp3 至 11.mp3 是当前歌单。</p>

<details>
<summary>发布与验证</summary>

<p>构建发布文件并在本地预览：</p>

<pre><code>npm run build
npm run preview</code></pre>

<p>将 dist 中的发布文件部署到静态托管服务即可。dist 已加入 Git 忽略列表，可在部署时从源码构建；build-manifest.json 记录本次有效文件，重复构建会保留旧哈希资源，方便兼容已经打开的页面。</p>

<p>使用预压缩副本需要托管服务支持内容协商：根据 Accept-Encoding 返回对应文件，设置 Content-Encoding、Content-Type 和 Vary: Accept-Encoding。带内容哈希的资源可长期缓存，HTML 与音频应重新验证。未配置预压缩时，普通文件仍可正常访问。</p>

<p>构建、资源、缓存和音频分段请求检查：</p>

<pre><code>npm test</code></pre>

<p>安装浏览器测试依赖并运行完整检查：</p>

<pre><code>npm ci
npx playwright install chromium
npm run check</code></pre>

<p>也可设置 BROWSER_EXECUTABLE_PATH 使用已有的 Chrome 或 Edge。浏览器检查结果写入 test-results/browser.json；开发依赖、构建产物和测试结果均不进入 Git 提交。</p>

</details>
